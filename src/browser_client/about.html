Project SONAR

About Project SONAR

Self-Organizing Network of Aggregated Representations

A project by MIT Media Lab

What is SONAR?

SONAR is a collaborative learning platform where users improve their machine learning models without sharing raw data. Participants share model representations, ensuring privacy.

How Does It Work?

SONAR uses a peer-to-peer network similar to BitTorrent, allowing devices to exchange model weights and insights directly while keeping raw datasets local.

Our cross-language system supports both browser-based JavaScript and Python nodes, making advanced ML accessible across platforms.

Why Use SONAR?

  • Privacy-Preserving: Data stays on your device
  • Accessible: Browser & Python clients
  • Efficient: Lower computational cost
  • Effective: Centralized-quality performance
  • Democratized: ML for everyone
